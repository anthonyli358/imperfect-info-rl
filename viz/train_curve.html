Self-play · policy gradient

Learning Ventures from scratch

A linear softmax policy trained by REINFORCE self-play, rated every few updates on an Elo scale anchored to two fixed opponents. With no prior knowledge it climbs to decisively beat the random baseline — and plateaus below the hand-tuned deck-clock heuristic, about where a purely linear policy should land.

Anchors: random = 1000 Elo by definition; heuristic pinned by its score vs random. Reproduce with uv run python -m experiments.train_ventures.
